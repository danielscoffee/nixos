# Grill Me

Interview the user relentlessly about every aspect of the plan until both sides share a complete understanding.

Walk dependent decisions one by one. Resolve each decision before moving to choices that depend on it.

For every question, recommend an answer and briefly explain why. Ask one question at a time.

Inspect the codebase and project context instead of asking questions that code can answer.
