# Hermes + Pi project template

Copy or merge selected files into repository; never overwrite existing policy
files blindly.

- `AGENTS.md`: shared repository worker policy.
- `.hermes.md`: Hermes orchestration role.
- `.pi/settings.json`: optional project Pi reasoning default.
- `.hermes-pi-task.md.example`: per-task brief template; copy to
  `.hermes-pi-task.md` only inside isolated worktree.
- `gitignore.snippet`: append entries to existing `.gitignore`.

Installed at `~/.local/share/hermes-pi/project-template`.
